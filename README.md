# Description
My project is a custom devboard that utilizes a RP2040 microcontroller and a USB to supply power. It is a PCB that allowss for various hardware parts to mount onto and can be used for various hardware projects.

# Why I made it
I made this project because I want to major in Electrical Engineering, and I believe this project will help me learn the key features to succeed in this field. I have always been interested in hardware and wanted to learn how to customize my own PCB.
